# Explorer-Congressional-Letters-105

Letters from Congress: letters members of the 105th Congress published on their own websites, preserved by the Wayback Machine. Start at the Letters from Congress home page, all letters from every Congress: https://robin-ia.github.io/Explorer-Letters/

Built output, published with GitHub Pages at <https://internetarchivecanada.github.io/Explorer-Congressional-Letters-105/>.
Never edited by hand: it is built from
[Congressional-Letters-Dev](https://github.com/Robin-IA/Congressional-Letters-Dev)
(`build/build_congress.py`, `build/export_csv.py`, `build/build_hub.py`) and
pushed from there. The letters themselves are not stored here: every one opens
from the Wayback Machine.
